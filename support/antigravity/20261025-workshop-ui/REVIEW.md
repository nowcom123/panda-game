# Codex 통합 검토 — 2026-10-25

## 수정 사항

- 작업대 실행 시 새 비용/결과를 몰래 재계산하지 않고 화면에 표시한 UpgradeQuote를 실행한다.
  다른 경로에서 무기/재료가 변경되면 원래 미리보기는 거절하고 다시 보여준다.
- 작업대 글자 확대, 긴 무기명 2줄 표시 및 줄바꿈, 실행 버튼 문구 단축.
- 강화 설명에서 내부 material/affix ID 제거. 강화 비용/상한 설명을 RECIPES에서 가져온다.
- 상한보다 높은 기존 옵션을 가진 무기의 미리보기가 하향 수치로 보이지 않게 한다.
- 폰트에 없는 아이콘 문자 제거. 탐험 가방 용량바를 DirectFrame 도형으로 교체하고
  본문 카드가 경고 문구를 덮지 않게 높이 조정.
- 삭제 확인창 뒤 화면의 클릭을 차단하고 닫을 때 이름 입력 포커스를 해제한다.
  ESC는 기존 game.handle_escape 경로를 사용하여 별도 키 바인딩 등록/해제를 제거했다.
- 삭제 안내 글자를 키우고 내용을 간결하게 정리. 중복된 작업대 세션 정리 코드 제거.
- 캡처 스크립트의 720p 설정이 constants.py 기본값에 덮이던 문제 수정.
  게임 import 이후 크기를 지정하고 실제 PNG 크기를 assert한다.
