# Codex 검토 — 2026-10-24

1단계 아이템 데이터·저장 API 구현을 검토하고 아래 문제를 수정했다.

- 동일 UID 추가가 기존 물건을 덮어쓰던 동작을 오류로 변경했다.
- 역직렬화 시 숫자·null UID를 문자열로 바꾸는 암묵 변환을 제거했다.
- 장착 슬롯 누락/추가 키를 무시하지 않고 검증한다.
- 명시적 카탈로그 없이 equip을 호출해도 재료를 장착하지 못하게 했다.
- 카탈로그 버전의 bool 허용과 JSON 중복 키에 의한 데이터 소실을 차단했다.
- 백업도 임시 파일+fsync+os.replace로 기록한다. 백업 기록 실패 시 저장을 중단한다.
- I/O 실패를 손상 JSON으로 삼키지 않고 호출자에게 전달한다.
- 미래 버전 백업도 저장 시 보호하고, 임시 파일은 실패 시 정리한다.

검증: 전체 208개 테스트 통과(안티 구현 후 199개 + 검토 회귀 검사 9개).
임시 디렉터리의 독립 생성·저장·복원·백업 복구 예제도 통과했다.
검사에서 실제 사용자 저장 경로나 rankings.json을 쓰지 않았다.

현재 완료 범위는 엔진 독립 데이터/저장 API다. 실제 게임의 장착 UI, 무기 옵션 적용,
드롭·자동 저장은 아직 연결하지 않았다. 후속 단계는 인벤토리·장비 적용이다.
