# Codex 검토 — 2026-10-24

Antigravity 구현을 검토하고 실제 캡처에서 소모품과 장비 UI가 겹치는 문제를 발견해 수정했다.
소모품 위젯 목록의 이름이 실제 위젯과 달랐으며, 카드·상세·유물 표시가 숨겨지지 않았다.
기본 무기를 재료 수량으로 설명하던 문자열 비교도 수정했다.

추가 보완:
- 새 런 초기화 후 예비탄이 이전 값으로 다시 덮이는 문제 수정.
- 탄약 보급 시 다른 무기 종류의 RPG 예비탄 풀에도 반영.
- 장전 완료는 현재 예비탄에서 차감하여 보급/반환분을 반영.
- 슬롯 전환 시 ADS 해제.
- 최초 기본품 저장 실패는 정상 세션으로 진행하지 않고 시작 차단.
- 저장소 초기화 예외를 무시하고 일반 게임으로 진입하던 경로 차단.
- 기본품 저장은 메뉴 로드가 아니라 일반 게임 최초 시작으로 지연.
- 사격장에서는 장비 UI의 장착/해제/잠금 쓰기 차단, 1/2 입력도 기존 소모품 경로 유지.
- 사격장에서 일반 게임으로 직접 진입해도 RPG 전투 세션 복원.
- 일반 RPG HUD의 1/2 안내를 주/보조 무기 선택으로 변경.

검증:
- unittest 전체 226개 통과.
- verify_equipment.py: 같은 AR의 옵션 분리, 전환·장전 취소, 미장착 무기 접근 차단 통과.
- verify_equipment_ui.py: 실제 게임 1600×900 렌더, 겹치는 위젯 숨김, 예비탄 초기화,
  keep_ammo 유지, 타 무기 보급, 사격장 장비 변경 차단, 인벤토리 닫기 통과.
- 검증은 TemporaryDirectory의 저장소만 사용했다.

아직 던전 장비 드롭이나 옵션 추첨은 없다. 기본품은 옵션 없는 일반 무기이며,
옵션이 있는 아이템의 전투 적용은 임시 프로필을 이용해 검증했다.
