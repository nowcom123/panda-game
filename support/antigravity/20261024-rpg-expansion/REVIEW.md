# Codex 검토 — 2026-10-25

Antigravity 결과물 A2/B/C를 검토하고 아래 문제를 수정했다.

## 실제 게임 연결

- 캐릭터 전환이 존재하지 않는 `reset_ammo_states`를 호출하던 문제 수정.
  실제 `reset_state`를 사용하고 이전 캐릭터의 아이템별 탄약 캐시/선택을 정리한다.
- 후보 캐릭터의 프로필을 검증한 뒤 목록 선택을 저장하고 세션을 전환한다.
  손상된 후보는 기존 세션을 유지하고 실패 원인을 전달한다.
- 캐릭터 생성/선택 목록 저장 실패 시 메모리 목록/선택도 원래대로 돌린다.
- 중복 UUID/목록 외 활성 UUID를 거절하며, UUID를 정규화한다.
- 이미 등록된 캐릭터의 저장 파일이 사라졌을 때 빈 프로필로 대체하지 않는다.
- 미래 버전 목록 백업을 덮어쓰지 않는다. 이관 재시도 시 기존 목적지 프로필을 재사용한다.
- 시작 실패 전 게임 UI를 먼저 숨기던 호출을 제거한다.

## 보스

- 실제 PlayerController에는 pos가 없다. 봉인 생성 때 이 속성을 사용해 보스 중심에 겹치던
  문제를 수정했다. 시전 시작 시 검증한 좌우 위치를 발동 시 사용한다.
- 발동 시 위치가 막혔으면 보호와 패턴을 취소하며 무료 약점 노출 보상을 주지 않는다.
- 부채꼴의 위험 영역을 실제 판정과 같은 12~60도, 반경 14m의 면으로 표시한다.
  중앙 안전 통로 경계도 ±12도로 맞췄다.
- 봉인 파괴의 2초 스턴 뒤에 회복 2초가 추가되는 중복을 제거했다.
  시간 만료는 약점 노출 보상을 주지 않는다.

## UI

- 장비 패널 글자를 확대하고 상세/비교 영역 줄바꿈 및 간격 조정.
- 비교값의 개선/악화를 녹색/붉은색으로 표시, 동일 수치는 중립 유지.
- 헤더 테두리에 겹치던 탭 위치 조정.
- 실제 입력과 다른 안내 수정: 3=탄약팩, 4=수류탄.

## 검증

- 전체 unittest 272개 통과. 새 검토 회귀 검사 7개 추가.
- 독립 expansion 검증 통과.
- 실제 게임 객체로 캐릭터 선택/새 생성/다시 전환, 세션 참조, 캐시 격리,
  목록 저장 실패 시 이전 선택/세션 보존 및 탐험 중 전환 차단 확인.
- 기존 loot 통합 검사 통과: 일반/보스 드롭, 저장 실패 시 탈출 대기,
  메뉴 우회 차단, 재시도 성공, 중복 승리 처리.
- 1600×900 및 1280×720 오프스크린 렌더 캡처를 생성하고 장비 화면/캐릭터 화면 확인.
- 통합 검사는 임시 저장소 사용. loot 검사는 순위 저장 mock 적용.
- 실제 수동 플레이 난도/장시간 성능은 이번 검증 범위에 포함하지 않았다.

현재 영구 저장 범위는 캐릭터별 장비·통화·해금이다.
레벨과 퍽은 여전히 탐험 단위이며 영구 캐릭터 레벨 성장/직업 시스템은 아직 없다.
