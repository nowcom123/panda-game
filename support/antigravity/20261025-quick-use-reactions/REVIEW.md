# Codex 통합 검토 — 2026-10-26

Antigravity 결과를 실제 코드와 게임 객체로 검토하고 아래 결함을 수정했다.

## 발견 및 수정
- 모든 적에게 파수견 전용 skip_dodge 인자를 전달하여 일반 적/보스 피격 시 TypeError가 발생했다. 파수견에만 전달하며 이전 회피 플래그를 정리한다.
- 마녀/해골의 update에 파수견 전용 chunks 인자를 전달하여 회피 첫 AI 틱에서 TypeError가 발생했다. 종류에 맞는 호출로 수정했다.
- 독 처리에서 PlayerController.take_damage가 지원하지 않는 damage_type을 전달했다. DOT 경로를 추가하고 일반 피격 무적 시간을 우회하되 연장하지 않으며 매 프레임 소리/화면 흔들림을 발생시키지 않는다. 마지막 독 틱은 실제 남은 지속시간까지만 계산한다.
- counter_pending 검사가 is_guarding보다 먼저 실행되어 예고 중 후속 탄환에 방어가 적용되지 않았다. 기존 방어를 먼저 처리하고 새 반격만 제한한다.
- 방어 성공 탄환의 넉백으로 적이 예고 위치에서 밀려나지 않도록 처리했다. 기존 캐스팅/공격 중 새 반응도 제한한다.
- 반격의 치명타격 후 게임 오버가 누락될 수 있어 director에서 즉시 처리한다.
- 회피 반환값이 치명타 성공으로 해석되는 문제를 수정했다. 피해 통계/부유 숫자는 실제 HP 감소량으로 집계한다.
- 마녀 순간이동 후보는 로드된 청크 내로 제한했다.
- 빠른 선택창의 미선택 기본값을 통일하고 중복 close/키 릴리즈, 외부 상태 변경 후 사용을 막았다. 사용 직전 실효 단축키와 수량을 다시 검사한다.
- 창 포커스 상실 시 소모 없이 취소하고 일시정지로 전환한다. 이동 키 잔여 상태, 모달 중 조준, 닫힌 뒤 누른 채 남은 사격을 정리한다.
- 빠른 사용 카드/글자 크기를 확대하고 카드 전체를 덮던 선택 색상을 상단 선으로 변경했다. 긴 효과 설명은 줄바꿈하고 수량은 별도 위치에 표시한다.
- Antigravity 캡처 스크립트가 기본 세이브로 앱을 먼저 생성하던 부분을 임시 save_path 주입으로 변경하고 순위 저장도 차단했다.
