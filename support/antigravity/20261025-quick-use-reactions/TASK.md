## A. ` 키 빠른 사용창

일반 PLAYING에서 백틱 키를 누르고 있는 동안 빠른 선택창을 표시한다.
선택하고 키를 놓으면 1회 사용. 선택하지 않았으면 소모 없이 닫는다.
원형 선택 영역 또는 분리된 카드 3~6개를 사용할 수 있다. 중앙 취소 영역과 선택 강조 테두리,
아이콘/이름/개수/짧은 효과 설명을 표시한다. 마우스 또는 휠로 선택 가능하게 한다.
휠은 이 상태에서 무기를 교체하면 안 된다. ESC는 취소. 숫자키/발사/재장전/Tab과 충돌 금지.

아이템 필터는 **현재 실제 단축키 배정** 기준이다.
- 일반 RPG 모드에서는 1/2가 무기 슬롯이므로 응급키트·아드레날린은 빠른 선택창에 포함한다.
- 3/4로 사용 가능한 탄약팩·수류탄은 제외한다.
- quick_slot=None인 공격 강화제 등은 포함한다. 수량 0인 것은 제외한다.
- 재료/장비/미확보 전리품은 대상이 아니다. 신규 아이템 ID는 만들지 않는다.

입력은 player_controller.py의 바인딩 구조에 연결한다. 백틱 키의 실제 Panda3D 입력 이벤트를 확인한다.
키 반복/키를 누른 채 창 전환/포커스 상실/동일 프레임 release 중복에도 한 번만 실행한다.
이름 입력 중인 타이틀·삭제창/설정/사격장/탈출 대기 등에서는 열리지 않는다.

전용 QUICK_USE 상태로 짧은 선택 동안 전투를 일시정지한다.
적/투사체/플레이어 이동/남은 탐험 시간/불릿타임 잔여시간 모두 멈추고 UI만 갱신한다.
이 기능은 불릿타임을 켜거나 끄지 않는다. 닫으면 이전 감속 상태를 그대로 이어간다.
열 때 사격/조준을 중단하고 마우스를 풀며, 닫을 때 입력 눌림 잔여/마우스 델타를 정리한다.
사망·승리·다음 층·재시작·메뉴·앱 포커스 이탈 시 선택 취소와 모달/입력 상태 정리.
실행 직전에 보유 수량과 상태를 재검증하고 PlayerController.use_item(item_id, combat, game)를
재사용한다. 별도 재료 차감/시간 버프 구현 금지. 사용 실패 메시지와 HUD 수량 갱신.
구현 파일은 quick_use.py / UI 패널 등으로 분리하고 game.py/ui_manager.py는 연결 중심으로 수정한다.

## B. 반응 공통 전투 연결 — 가장 중요한 부분

현재 파수견은 take_damage 안에서 random<.35를 검사하고 combat_system.py는
last_action_dodged를 확인해 **파수견 전용** 텍스트를 출력한다. 이를 다른 적에도 통하는 결과로 연결한다.

- 한 발 발사(shot_id)·한 대상당 확률 판정 1회. 샷건 8펠릿이 8번 반격을 발생시키면 안 된다.
- 최초 적중 펠릿이 0번이 아닐 수도 있다. p_idx==0만으로 회피/방어 출력 조건을 만들지 않는다.
- 같은 발사에서 같은 적을 다시 맞히면 캐시된 반응 결과를 재사용하고 반격을 재생성하지 않는다.
- 기존 파수견 내부 RNG와 새 판정을 동시에 수행하지 않는다. 기본 회피 확률은 35% 유지.
- 사망/시체/경직/현재 반응·반격 예고 중이면 새 반응 발동 금지.
- 초기 범위는 직접 발사한 총탄. DOT/폭발/도탄/전기 연쇄/환경 피해에는 새 반응을 발동하지 않는다.
  기존 특수 피해 경로의 의미를 보존하고 명시적 공격 컨텍스트로 구분한다.
- 반응 결과는 해당 타격에만 유효. 다른 몬스터/다음 타격에 dodge/blocked 플래그가 남지 않게 한다.
- take_damage 기존 호출자는 유지한다. 게임·tests의 __new__/SimpleNamespace 객체와도 기본값으로 호환.
- 회피 성공 시 해당 적중 피해 0. 지속 피해는 회피 중에도 정상 적용된다.
- 방어는 전방 120도(좌우60도) 총격에만 적용한다. 후면 사격은 정상 피해, 반격 발동 없음.
  뱀은 피해60% 감소, 골렘은65% 감소. 짧은 방어 시간 중 전방 피해만 계속 감소하고
  반격은 최초 발동에 1회만 예약. 방어 중에도 후면 공격과 DOT/폭발로 대응 가능.
- 회피/방어 중 적의 일반 공격·캐스팅과 반격이 중첩되지 않게 한다.
- UI 피해 숫자/누적 피해/흡혈/연계/샷건 저지력은 실제 적용 결과 기준.
  전혀 피해를 주지 않은 회피가 피격 효과·흡혈·헤드샷 보상·stagger를 주면 안 된다.
  방어 성공 시 앞에서 맞은 펠릿은 샷건 3발 저지력 카운트에서 제외한다. 측후방 적중은 기존 유지.
- 강화된 무기/약점/퍽의 배율은 그대로 계산하고 마지막에 방어 피해 감소를 적용한다.
  boss skull 보너스 등 기존 실제 HP 변화 통계도 회귀 확인.

## C. 몬스터별 연출과 반격

### 마녀: 순간이동 회피만
회피 성공 시 2.5~4m 옆 공간으로 이동. 플레이어의 바로 뒤/몸 안/벽 안으로 이동하지 않는다.
후보는 벽 충돌, 바닥 높이, 이동 경로 LOS, 플레이어 최소2m 거리로 검증한다.
유효 후보가 없으면 회피 취소+정상 피해. 벽을 뚫거나 전투 공간 밖으로 탈출하지 않는다.
출발/도착에 짧은 잔상·가루 연출. 별도 방어/반격은 없음.

### 해골: 분해 후 재결합 회피만
몸통·팔·다리 뼈가 잠깐 흩어지고 원위치에서 .45초 내 재결합하는 것이 보여야 한다.
기존 관절/히트박스 참조를 제거하지 않는다. 위치/스케일/가시성 복구를 명확히 하고
회피 중 사망/메뉴/파괴/청크 전환에도 잔해와 보이지 않는 적이 남지 않게 한다.
원래 위치의 벽 충돌은 유지. 별도 방어/반격 없음. 물리 강체 수십 개 생성 금지.

### 뱀: 방어 성공 시 맹독 브레스
전방 방어 성공 → .85초 녹색 부채꼴 예고 → 7m, 좌우25도 브레스 1회.
예고 시작 시 방향을 고정하고 발동 때 자동 추적 회전하지 않는다.
실제 위험 판정과 표시 범위 일치, 벽 뒤 공격 금지.
명중 시 즉시10 피해 + 3초 동안 초당4 독 피해(총12). 같은 독은 누적하지 않고 시간 갱신.
독은 world_dt로 진행, 슬로모션/일시정지에 맞춤. HUD에 남은 독 상태를 간결히 표시.
적 사망으로 아직 발동하지 않은 브레스는 취소. 이미 걸린 독은 정해진 시간만 지속하되
런 종료/새 런에는 플레이어 독 상태를 제거한다. 동료 적·보스에게 독 전염 없음.

### 골렘: 방어 성공 시 강력한 지진
방어 성공 → 1.0초 바닥 원형 예고 → 반경8m 지진, 피해24 + 짧은 카메라 진동.
예고 중 피해0, 발동당 최대1회, 벽 뒤 피해 금지. 발높이 .75m 이상 점프 또는 범위 이탈로 회피.
GroundShockwave는 기존에 피해 없는 시각 효과다. 별도 타격과 이중 피해가 되지 않게 한다.
기존 진흙 오크 slam과 동시에 실행하지 않는다. 반격 종료 후 기존 공격 쿨다운도 최소1초 유지.

공통: 새 타이머/독/반격은 애니메이션 LOD와 분리하여 world_dt로 매 논리 업데이트 갱신한다.
geometry를 매 프레임 만들지 않는다. 동시에 존재하는 효과 수/생명주기를 제한한다.
원근거리, 불릿타임, 낮은 FPS/큰 dt에서도 예고→한 번 발동→정리 순서 보장.

## D. 플레이어 대응 능력치와 성장

새 능력치(기본값 모두0):
- 회피 억제: 적 회피 확률에서 %p 차감. 탄도/조준을 무작위 명중 판정으로 바꾸지 않는다.
- 방어 관통: 적 방어의 피해 감소율을 일정 비율 무시. 방어 발동 확률 자체는 바꾸지 않는다.

counter_stats와 reaction_chance/guarded_damage를 재사용한다.
예: 뱀 100피해 → 방어 시40, 관통30%면58. 마녀25%회피 → 회피억제15%p면10%.

기존 퍽 체계에 2종 추가:
- precision_training / 정밀 조준: 1~3레벨, 회피 억제5/10/15%p.
- guard_breaker / 방어 파쇄: 1~3레벨, 방어 관통10/20/30%.
max_level=3, 최대 레벨이면 선택 후보 제외. 기존 armor_piercing(대상 관통) 퍽과 별개다.
중복 선택 레벨 증가와 카드의 현재→다음 설명, 새 런 초기화까지 기존 규칙에 연결한다.
능력치 값은 퍽 레벨에서 계산하며 별도 영구 프로필 필드는 추가하지 않는다.
인벤토리 상태 카드에 두 수치를 표시하되 레이아웃/유물/슬롯이 겹치지 않게 한다.
전투 결과 통계 accuracy(명중률 기록)와 이 두 RPG 능력치를 혼용하지 않는다.
몬스터 성공 피드백은 각각 순간이동/분해 회피/독 방어/지진 방어로 구분하며 스팸 출력 금지.

## E. 작업 순서와 반환

1) 빠른 사용창 독립 구현/검증 → 2) 반응 판정·플레이어 능력치 → 3) 몬스터 연출/반격 → 4) 통합 검증.
기존 수정/삭제된 에셋 보존, git reset/clean/commit 금지. 실제 세이브·rankings.json 사용 금지.
최신 UI의 consumables_root 부모 단위 숨김을 유지한다. 다른 UI 갱신으로 패널이 다시 나타나면 안 된다.

필수 검사:
- 빠른 선택창의 실효 단축키 필터, press/repeat/release 1회 소비, 선택 없음/ESC/포커스 상실 취소,
  수량 소진, 일시정지/불릿타임 보존, 새 런/사망/메뉴 정리, 마우스 잠금 복구.
- RNG 주입 고정 테스트: 4종 역할 제한, 확률·능력치 경계, 전방/후방 방어, 쿨다운.
- 실제 샷건 8펠릿/연사/후속 타격에서 1회 반응, 회피의 피해·보상0, 방어 후 실제 피해 통계.
- 마녀의 막힌 이동 후보, 해골 복구/사망, 브레스/지진 예고 중 피해0·벽·점프·단일 피해,
  독 누적 방지/저프레임/일시정지/새 런 정리.
- 기존 보스·장비·작업대·삭제·탈출 및 사격장 테스트 회귀 없음.
- 임시 저장 경로 실제 게임 통합 검사. 각 몬스터 반응과 빠른 선택창 캡처를 남긴다.
- UI는 게임 import 후 해상도를 설정하고 PNG 실제 크기를 확인(1280×720, 2294×1201).

완료 범위/변경 파일/검증 결과/한계를 같은 폴더 RESULT.md에 작성한다.
미완료를 완료로 기재하지 않는다. 사용자에게 이 문서를 반복해서 붙여넣도록 요구하지 말고
가능한 구현 범위를 모두 처리한 뒤 반환한다. 사용자가 Codex에 '안티 작업 끝' 전달 시 통합 리뷰한다.
