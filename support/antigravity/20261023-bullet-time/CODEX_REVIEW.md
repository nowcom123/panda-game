# Codex 검토 — 2026-10-23

## 결론

Gemini의 결과는 비교 제안과 독립 프리뷰이며 새 불릿타임 효과는 게임에 적용되지 않았다. 샤프닝은 여전히 기본 OFF인 독립 설정이다.

권장 우선순위:
1. 탄피·피격 파편의 물리와 수명만 월드 시간 0.35배로 감속한다. 발사·재장전·카메라는 실시간 유지.
2. 현재 즉시 바뀌는 불릿타임 FOV와 약한 청회색/채도 감소 효과에 부드러운 진입·종료 전환을 적용한다. FOV 추가 확대보다 기존 변화의 보간을 우선한다.
3. 기존 시각용 탄도 궤적 감속은 선택 사항으로 둔다. 즉시 명중 판정과 뒤늦게 도착하는 시각 효과의 불일치 및 화면 혼잡을 검토해야 한다.

## 확인한 사실과 수정

- `combat_system.py`의 탄피 갱신은 실시간 dt를 사용한다. 월드 감속과 분리된 상태라는 분석은 맞다.
- 불릿타임 FOV는 현재 +6.5도가 즉시 적용된다. 전환 보간은 유효한 개선 후보이다.
- 원래 샤프닝 ON 프리뷰는 uniform만 직접 변경했다. 캡처 안에서 파이프라인 갱신이 이를 OFF로 덮어써 ON/OFF 이미지가 동일했다. `pipe.set_sharpening()`을 사용하도록 수정하고 실제 픽셀 차이를 검사했다.
- 원래 탄피 ‘슬로모션/궤적’ 이미지는 탄피 두 개를 정지 배치한 사진이다. 시간 진행이나 궤적 생성이 없어 감속의 증거가 아니다. 새 출력 이름을 `preview_casing_static.png`로 바로잡았다. 기존 `preview_casing_tracer_slowmo.png`는 과거 미검증 산출물로만 취급한다.
- 현재 색조 프리뷰는 톤매핑 전 HDR 색상에 22% 혼합을 적용한다. 화면 출력의 채도가 정확히 22% 줄었다는 뜻은 아니다. 위험 링과 안광이 ‘훨씬 선명’해진다는 주장도 측정되지 않았다. 정지 프리뷰에서 링은 여전히 옅다.
- 보고서의 ‘부하 0’, ‘GPU 0.01ms 이하’, ‘ALU 4개’, ‘완벽한 오디오 동기화’와 ‘무결점 연동’은 검증 근거가 없다. 감속으로 파티클이 더 오래 남으면 평균 활성 개수와 렌더 비용이 늘 수 있다. 원본 RESULT.md는 협업 기록으로 보존한다.

## 검증 결과

- 수정 프리뷰 GPU 렌더 성공: 색조 변경 픽셀 1,292,768개, 독립 샤프닝 변경 픽셀 272,573개 (이미지 전체 기준, 성능 수치 아님).
