# Gemini 협업: 불릿타임 연출 비교안

프로젝트: `C:\Users\nowco\Desktop\Dream\panda-game`

사용자가 Antigravity 모델을 Gemini로 변경했다. 실제 선택된 Gemini 모델을 사용하고 결과에 실제 모델명을 기록한다. Sonnet으로 변경할 필요는 없다. 사용자가 이 지시서를 직접 입력하는 협업 방식이다.

## 요청과 현재 구현

사용자 요청: 불릿타임의 자동 샤프닝을 제거하고, 샤프닝은 설정에서 ON/OFF할 수 있게 한다. 슬로모션을 더 잘 살릴 효과를 제안한다.

Codex 완료:
- `post_processing.py`의 GamePostProcessing: 일반 화면 선명도 옵션, 기본 OFF. HUD 제외.
- `ui_manager.py`: ESC 설정의 화면 선명도 ON/OFF 버튼. 즉시 적용.
- `game.py`: 불릿타임과 샤프닝 연결 제거. 불릿타임 시작/종료가 옵션에 영향을 주지 않는다.
- 설정은 현재 실행 세션 동안 유지되며 기존 다른 설정과 마찬가지로 앱 재실행 후 저장/복원은 구현하지 않았다.
- 기존 불릿타임 소리와 HUD는 유지했다. 신규 슬로모션 효과는 아직 적용하지 않았다.

## 이번 작업: 제안과 비교 검토

사용자는 새 효과를 무엇으로 할지 물었다. 아래 안을 코드와 화면을 근거로 비교하고 `RESULT.md`에 추천을 작성한다. 이번 단계에서 새 효과를 실제 게임에 기본 적용하지 않는다. 비교용 구현이 필요하면 이 폴더 안의 독립 프리뷰 스크립트로만 만든다.

### 우선 추천 조합

1. **탄피와 파편의 느린 움직임**: 월드의 0.35배 시간과 시각 효과의 시간이 일치하는지 확인한다. `combat_system.py`의 `self.casing_effects.update(dt)`는 플레이어용 실시간 dt를 받으므로 별도 시각 효과 dt 분리가 후보이다. 발사·장전·카메라 입력 속도를 함께 늦추지 않는다.
2. **짧고 옅은 이동 궤적**: 기존 tracer 구현을 먼저 확인한다. 탄도를 새로 중복 생성하지 않는다. 플레이어 총알은 기존 즉시 명중 판정을 보존하고 시각적 궤적만 검토한다. 실제 투사체에는 짧은 잔상을 검토한다. 탄피 잔상은 과하면 생략한다.
3. **약한 채도 감소 + 차가운 색조**: 채도 15~25% 감소, 청회색을 약하게 가미하는 값을 비교 시작점으로 삼는다. 적의 안광·위험 예고·피격 확인이 구분되어야 한다. 중앙 조준부와 HUD를 흐리지 않는다.
4. **전환감**: 시작 0.15~0.25초, 종료 0.2~0.35초 동안 효과 강도를 보간한다. 기존 저음 감속 사운드와 기존 FOV 연출을 조사하고 중복 효과를 얹지 않는다.

전체 화면의 강한 모션블러, 과한 색수차, 큰 섬광, 추가 급격한 FOV 변화는 우선안에서 제외한다. 조준 시인성과 사용자의 기존 성능 우려를 고려한다.

## 검토 범위와 비용

- 관련 파일: `post_processing.py`, `combat_system.py`, `casing_effects.py`, `projectiles.py`, `game.py`, `ui_manager.py`.
- 먼저 관련 메서드만 읽는다. 저장소 전체 재분석이나 기존 완료 작업 재구현은 하지 않는다.
- `audio_system.py`, `rankings.json`, 보스·퍽·내비게이션 코드를 수정하지 않는다.
- 프리뷰에서는 풀링/상한을 적용한 가벼운 효과를 우선한다. 프레임마다 새 노드/지오메트리를 무제한 만들지 않는다.
- FPS 측정 없이 성능 향상이나 무부하를 단정하지 않는다.
- 커밋/푸시/의존성 변경을 하지 않는다.
