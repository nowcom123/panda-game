# 인벤토리 겹침 수정 — 2026-10-25

원인: 장비 장착/해제/잠금 콜백이 `_refresh_inventory_ui()`를 호출하고,
이 함수가 inv_detail_icon.show()를 호출해 다른 탭에서도 소모품 상세 아이콘을 다시 노출했다.
이전 검증은 탭을 바꾼 직후의 캡처에 집중해 장착 콜백 이후를 확인하지 못했다.

수정:
- 소모품 전용 위젯 모두 consumables_root 아래로 묶었다.
  탭 전환은 이 부모의 표시 상태를 제어하므로 내부 show() 갱신이 다른 탭에 새어 나오지 않는다.
- 소모품 화면을 상태/6칸 배낭/상세 정보 카드로 재배치했다.
- 슬롯 크기와 행 간격, 아이콘 크기, 긴 이름 말줄임, 설명/사용 버튼 간격 조정.
- 유물 4개를 화면 하단에 분리 배치하고 푸터와의 간격 확보.
- 오래된 무기 수치/키 안내를 제거하고 현재 장비 정보만 표시.
- 일반 RPG 모드의 응급키트/아드레날린에 잘못된 1/2 단축키 안내가 나오지 않게 수정.

검증:
- 전체 unittest 300개 통과.
- verify_inventory.py: 임시 저장소의 실제 게임으로 AR 보조 장착 → 해제 → 잠금,
  다른 탭에서 강제 정보 갱신까지 수행하고 모든 소모품 위젯이 숨겨져 있음을 assert.
- 소모품 5종/빈 칸/유물 4개 화면, 긴 아드레날린 설명의 버튼 침범 여부 확인.
- 실제 응급키트 사용 후 수량 차감 및 표시 유지 확인.
- 1280×720과 사용자 스크린샷 원본 크기인 2294×1201로 실행·캡처.
- 검증은 임시 저장 경로를 사용하고 순위 기록은 비활성화했다.

실행:
`.venv/Scripts/python.exe support/antigravity/20261025-inventory-fix/verify_inventory.py 1280 720`
`.venv/Scripts/python.exe support/antigravity/20261025-inventory-fix/verify_inventory.py 2294 1201`
