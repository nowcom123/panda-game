# Panda Game - Liminal Backrooms FPS Escape

Panda3D 기반의 1인칭 호러 서바이벌 FPS 백룸 탈출 게임입니다.  
칠흑 같은 어둠 속에서 왼손 손전등과 오른손 12발 권총만으로 1분 안에 비상탈출구를 찾아 5초간 문을 사수하며 다음 스테이지로 진출해야 합니다.

## 주요 특징
- **스테이지 진행 & 괴물 속도 단계적 증가 (Stage Progression)**:
  - 비상문 5초 홀드아웃 성공 시 즉시 `STAGE CLEAR!` 알림과 함께 다음 스테이지(Stage 2, Stage 3...)로 진입
  - 스테이지가 올라갈 때마다 뱀 괴물과 해골 괴물의 이동 속도가 단계적으로 증가 (`1.0 + (stage - 1) * 0.18` 배속)
  - 스테이지를 거듭할수록 피할 수 없는 속도로 플레이어를 압박하는 극한의 서바이벌 스릴
- **스테이지 2부터 맵 내 탄약 상자 드랍 (Ammo Drops)**:
  - 스테이지 2부터 미궁 복도 곳곳에 3D 밀리터리 탄약 상자가 무작위 드랍 (은은한 황금빛 발광)
  - 플레이어가 탄약 상자 근접(1.8m) 시 자동 수거되어 예비 탄약 +12발 획득
- **R 키 재장전 시스템 (Reload Mechanic)**:
  - `R` 키를 눌러 예비 탄약에서 권총 탄창으로 즉시 재장전 (1.2초 재장전 딜레이 및 총기 기울임 애니메이션)
  - HUD에 현재 탄창 탄약과 예비 탄약이 실시간 표시: `[ 탄약: 12 / 12 | 예비: 24 ]`
- **넓고 쾌적해진 현대적 POV 시야각 (Wider FOV & Viewmodel Distance)**:
  - 카메라 기본 FOV를 75°에서 **88°**로 확장하여 넓고 시원한 시야 확보
  - 얼굴에 너무 가깝던 왼손 손전등과 오른손 권총 뷰모델 위치를 전방으로 더 멀리 배치하여 자연스러운 FPS 1인칭 시점 완성
- **비상탈출문 5초 개방 홀드아웃 & 현실적 강철 방화문**:
  - 판타지풍 초록빛/기둥/비콘을 100% 제거하고 어둠 속에 묻힌 중장갑 강철 방화문(Reinforced Blast Door)과 3단 잠금 빗장으로 구성
  - 탈출문 2.8m 앞에서 **5초 동안 버텨야** 문이 열리고 스테이지 클리어
  - 구역을 벗어나면 개방이 중단되고 타이머가 리셋되는 긴박한 디펜스 시스템
- **1인칭 듀얼 웰드 FPS & 발광 총알 궤적 (Bullet Tracer)**:
  - **왼손 손전등**: 어둠을 가르는 강력한 집중형 스포트라이트와 1인칭 플래시라이트 모델
  - **오른손 12발 권총**: 프레임, 슬라이드, 가늠자/가늠쇠가 구현된 전술 피스톨
  - **선명한 총알 궤적**: 마우스 좌클릭 사격 시 총구에서 탄착점까지 뻗어나가는 고속 발광 탄도 라인 연출
  - 무기 바빙, 슬라이드 킥백 반동, 총구 화염 및 실시간 다이내믹 발사광
- **사격 적중 시 괴물 0.5초 경직 (Stun Mechanic)**:
  - 괴물 적중 시 **0.5초간 즉시 이동 정지 및 고통스러운 피격 흔들림**
  - 스턴 동안 플레이어 사망 판정이 발생하지 않아 문 앞 사수 및 긴급 탈출에 필수적
- **시네마틱 인트로 화면 & 자동 랭킹 시스템 (`rankings.json`)**:
  - 게임 실행 시 미궁 상공에서 360도 파노라마로 전경을 조망하는 시네마틱 인트로 카메라
  - **START / RANK / EXIT** 메뉴 버튼 제공
  - 플레이 종료 시 최종 도달 스테이지, 소요 시간, 잔여 탄약이 자동으로 영구 기록
- **광활한 252m x 252m 밀폐 시설 & 60 FPS 방어**:
  - 13.0m 심연 천장, 7x7 청크(1,764개 타일), 멀티스레드 비동기 청크 로딩, 드로우콜 병합(flattenStrong)

## 조작법
- **이동**: `W`, `A`, `S`, `D` (8방향 대각선 이동 가능)
- **사격**: `마우스 좌클릭` (권총 발사, 12발 탄창, 총알 궤적 표시)
- **재장전**: `R` (예비 탄약에서 12발 충전)
- **달리기**: `Shift` + 방향키 (스테미나 소모)
- **시선 전환**: `마우스`
- **마우스 커서 잠금/해제**: `ESC`
- **메인 메뉴 복귀 / 랭킹 확인**: 게임 종료 후 화면 버튼 클릭

## 실행 방법
```bash
# 의존성 패키지 설치
pip install panda3d simplepbr

# 게임 실행
python game.py
```
