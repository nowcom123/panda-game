# Panda Game - Liminal Backrooms Infinite Loop

Panda3D 기반의 무한 절차적 백룸 공포 미로 탈출 게임입니다.

## 주요 특징
- **광활한 3D 심연 공간**: 6.0m 너비의 광폭 복도와 **13.0m 초대형 심연 천장** 및 3.0m 웅장한 출입문
- **완전한 닫힌 방 구조**: 완벽하게 밀폐된 독립 방과 틈새 없는 0.8m 두께의 2단 벽체
- **칠흑의 어둠과 촛불**: 손전등과 은은하게 타오르는 3D 고딕 촛불, 실시간 빛 깜빡임 연출
- **기괴한 벽 타는 거미 괴물 AI (Wall-Crawling Spider)**: 
  - 8개의 긴 2단 관절 다리, 들썩이는 거대 복부, 독니, 번뜩이는 6개의 붉은 안광 클러스터
  - 복도 벽면을 타고 수직으로 기어오르는 **Wall-Climbing 물리 (고도 3.6m 등반 & 80도 틸트)** 및 바닥 급강하 습격
  - 초당 13회 다리를 엇갈려 두드리는 고속 스커틀링(Scuttling) 크롤링 애니메이션
- **8방향 이동 및 스테미나 시스템**: W, A, S, D 8방향 이동 (대각선 달리기 지원) 및 Shift 전력질주 시 스테미나 소모/회복 HUD
- **고성능 최적화**: 멀티스레드 비동기 청크 스트리밍, 촛대 원형 템플릿 인스턴싱, 드로우콜 병합(flattenStrong), 60 FPS 고정

## 조작법
- **이동**: `W`, `A`, `S`, `D` (8방향 대각선 이동 가능)
- **달리기**: `Shift` + 방향키 (스테미나 게이지 소모)
- **시선 전환**: `마우스`
- **마우스 커서 잠금/해제**: `ESC`
- **재시작**: `R`

## 실행 방법
```bash
# 의존성 패키지 설치
pip install panda3d simplepbr

# 게임 실행
python game.py
```
