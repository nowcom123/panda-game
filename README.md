# Panda Game - Liminal Backrooms FPS Escape

Panda3D 기반의 1인칭 호러 서바이벌 FPS 백룸 탈출 게임입니다.  
촛불 하나 없는 칠흑 같은 어둠 속에서, 왼손 손전등과 오른손에 쥔 12발의 권총만으로 1분 안에 탈출구를 찾아 탈출해야 합니다.

## 주요 특징
- **1인칭 듀얼 웰드 FPS 시스템 (Dual-Wield Viewmodel)**:
  - **왼손 손전등**: 어둠을 가르는 강력한 직선 원추형 스포트라이트와 1인칭 플래시라이트 모델
  - **오른손 12발 전술 권총**: 총열, 슬라이드, 트리튬 야광 조준기(Ironsights)가 구현된 1인칭 피스톨 모델
  - 이동 시 무기 바빙(Weapon Bobbing), 격발 시 총기 슬라이드 킥백 반동 및 총구 화염(Muzzle Flash) 실시간 다이내믹 조명
- **사격 및 0.5초 몬스터 스턴 (Stun Mechanic)**:
  - 마우스 좌클릭(`Mouse1`)으로 정밀 히트스캔 사격
  - 괴물 적중 시 **0.5초간 즉시 경직(Stun)** - 추격 이동 중지, 고통스러운 피격 흔들림, 스턴 시간 동안 플레이어 공격 불가
  - 단 12발의 제한된 탄약으로 위기 순간에만 적절히 활용해야 하는 서바이벌 긴장감
- **1분(60초) 탈출 미션 & 원거리 랜덤 탈출구**:
  - 게임 시작과 동시에 **60초 카운트다운 타이머** 작동
  - 스폰 위치로부터 **최소 70m 이상 떨어진 먼 복도 끝**에 완전 무작위로 생성되는 에메랄드 탈출 포탈
  - 3D 에메랄드 게이트, 공중으로 솟구치는 빛의 기둥, 맥동하는 그린 비콘 라이트
  - 60초 내 포탈 도달 시 **"탈출 성공!"**, 시간 초과 또는 피격 시 **"게임 오버 / 탈출 실패"**
- **완전한 칠흑의 어둠**:
  - 모든 촛불 및 보조 조명을 100% 제거하여 오직 플레이어의 손전등 빔에만 의존
- **듀얼 공포 추격 괴물 AI**:
  - **항상 무작위 랜덤 스폰**: 매 라운드마다 플레이어와 이격된 복도에 무작위 스폰
  - **초대형 거대 흑사 (`LongBlackSerpent`)**:
    - 머리 폭 1.4m, 길이 1.8m, 총 연장 **약 13.5m의 거대한 칠흑의 대사**
    - 14개의 거대 마디가 실시간 S자 파동(Sinusoidal Undulation)을 그리며 벽과 바닥을 타고 추격
  - **키 크고 팔이 긴 해골 괴물 (`TallSkeletonMonster`)**:
    - **약 4.2m 신장**의 초장신 해골 실루엣과 **2.7m의 기괴하게 긴 팔**
    - 아래턱이 탈구되어 쩍 벌어진 **Unhinged Jaw**와 공허의 **검은 눈동자**
- **미니멀 서바이벌 HUD**:
  - 화면 중앙 크로스헤어(`+`)
  - 상단: `[ 탈출 제한시간: MM:SS ]` 카운트다운 게이지
  - 하단: `[ 탄약: X / 12 ]` 탄약 상태 및 실시간 스테미나 바
  - 괴물 거리 표시를 일체 제거하여 극한의 청각/시각적 공포 선사
- **광활한 252m x 252m 밀폐 시설 & 고성능 최적화**:
  - 13.0m 심연 천장, 7x7 청크(1,764개 타일)
  - 멀티스레드 비동기 청크 로딩, 드로우콜 병합(flattenStrong), 60 FPS 방어

## 조작법
- **이동**: `W`, `A`, `S`, `D` (8방향 대각선 이동 가능)
- **사격**: `마우스 좌클릭` (권총 발사, 12발 한정)
- **달리기**: `Shift` + 방향키 (스테미나 소모)
- **시선 전환**: `마우스`
- **마우스 커서 잠금/해제**: `ESC`
- **재시작**: `R` (탄약 12발, 60초 타이머, 신규 랜덤 탈출구 리셋)

## 실행 방법
```bash
# 의존성 패키지 설치
pip install panda3d simplepbr

# 게임 실행
python game.py
```
