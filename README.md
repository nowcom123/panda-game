# Panda Game - Dark Fantasy Dungeon Survival

Panda3D 기반의 1인칭 다크 판타지 던전 생존 게임입니다. 쇠뇌와 소비 아이템으로 몬스터를 상대하며, 각 층의 제한시간 5분 안에 룬 제단 3개를 각인하고 탈출 관문에 진입합니다.

## 실행

프로젝트 폴더에서 실행합니다.

```bash
pip install -r requirements.txt
python game.py
```

## 게임 진행

- 인트로 → 로딩 → 플레이 → 스탯·유물 선택 → 다음 층 로딩 순서로 진행합니다.
- 제단 반경 2.5m 안에서 `E`를 1.5초 유지하면 각인이 완료됩니다.
- 제단 3개를 활성화하면 관문이 열립니다. 관문 반경 2.5m 안에서 0.8초 머무르면 층을 클리어합니다.
- 다음 층에서는 제한시간이 초기화되고, 쇠뇌 장전과 예비 볼트 18발 보급, 최대 체력의 45% 또는 45 중 큰 값만큼 회복이 적용됩니다.
- 스탯·유물·보유 소비 아이템은 다음 층으로 이어집니다. 새 게임을 시작하면 성장과 보유 상태를 초기화합니다.
- 메뉴로 돌아가면 이전 층의 투사체·화염·향로·보급품·제단·관문과 몬스터를 정리하고 안개와 HUD 효과를 복구합니다. 로딩 중 메뉴 복귀도 로딩 태스크를 취소합니다.
- 로딩·성장 화면·게임 오버에서는 전투 효과음과 몬스터 반복 음향을 중지합니다. 새 층에서는 이전 몬스터의 공간 음향 연결을 해제하고 다시 연결합니다.
- 체력이 소진되거나 제한시간이 끝나면 게임 오버가 되며 `rankings.json`에 결과를 기록합니다. 현재 최종 층 종료 조건은 없습니다.

## 탐색 나침반

화면 상단의 금빛 나침반은 시선에 따라 360도로 순환합니다. 북(N) 0°는 월드 +Y, 동(E) 90°는 +X, 남(S) 180°, 서(W) 270°입니다. 중앙 포인터는 현재 시선이며, 띠에는 전방 180도(좌우 90도)의 방위와 15도 간격 눈금을 표시합니다.

가장 가까운 미활성 제단은 해당 제단 색의 마름모로 표시하고 이름·직선거리를 함께 안내합니다. 뒤쪽 목표는 띠 끝의 화살표와 ‘뒤쪽’ 문구로 구별합니다. 제단 3개를 완료하면 표식이 열린 관문 모양으로 바뀝니다. 상점·로딩·게임 오버·메뉴에서는 나침반을 숨깁니다. 거리는 통로를 따라가는 경로 길이가 아닌 직선거리입니다.

## 층별 몬스터 편성

1·2층의 기존 편성은 유지합니다. 3층부터 다음 세 가지 테마가 순환하며, 로딩 화면에는 해당 층의 특징과 대응 요령을, 진입 시에는 4초간 테마 안내를 표시합니다.

| 층 | 테마 | 특징 |
|---|---|---|
| 3, 6, 9, … | 진흙의 파수대 | 오크·해골 증원, 근접 압박 |
| 4, 7, 10, … | 잿불의 회랑 | 마녀·뱀 증원, 원거리 공격과 접근 압박 |
| 5, 8, 11, … | 그림자 사냥터 | 스토커·뱀 증원, 도약 회피 |

몬스터 총수는 기존과 같은 1층 7마리, 2층 10마리, 이후 층당 2마리 증가입니다. 기본 편성과 2층 증원은 유지하고, 이후 증원 중 최대 3쌍을 테마에 맞게 교체합니다. 기존 이동속도 증가, 공격 피해·준비 시간, 5분 제한, 제단 3개와 보급·성장 규칙은 유지합니다. 테마는 몬스터 편성을 바꾸며 지형·조명은 기존 생성 방식을 사용합니다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| 마우스 | 시점 회전 |
| Shift + 이동 | 질주, 스태미나 소모 |
| 마우스 좌클릭 | 쇠뇌 발사, 빈 쇠뇌에서는 재장전 시도 |
| R | 재장전 |
| 마우스 우클릭 | 근접 강타·밀치기, 스태미나 18 소모 |
| E 유지 | 제단 각인 |
| 1 / 2 / 3 | 생명의 성수병 / 정화의 향로 / 비산 화약병 |
| ESC | 커서 잠금·해제 (게임은 계속 진행) |

## 전투·성장·파밍

- 쇠뇌는 1발 장전, 초기 예비 볼트 15발, 기본 재장전 시간 1.25초입니다. 볼트는 중력의 영향을 받는 투사체입니다.
- 볼트는 매 프레임 이동 구간에서 가장 먼저 만난 지형 또는 몬스터 표면에 충돌합니다. 벽·기둥·바닥·천장이 뒤쪽 몬스터를 차단합니다.
- 근접 강타는 공격 가능한 상태에서만 스태미나 18을 소모합니다. 재장전 중·강타 중·플레이 외 상태에서는 소모하지 않으며, 헛스윙도 실행된 공격이므로 소모합니다.
- 벽·바닥에 박힌 볼트와 시체의 회수 가능한 볼트는 근처에서 자동 획득합니다. 화살통 보급품은 예비 볼트 10발을 지급합니다.
- 몬스터는 검은 뱀, 장신 해골, 진흙 오크, 잿더미 마녀, 그림자 스토커의 5종입니다. 오크는 지진·슬로우, 마녀는 화염구, 스토커는 도약과 심장 약점을 사용합니다.
- 특수 공격에는 준비 동작과 몬스터 위치에서 들리는 예고음이 있습니다. 오크는 0.5초 동안 지진 범위와 커지는 바닥 원을, 마녀는 0.4초 동안 지팡이의 빛과 고리를 표시합니다. 스토커는 0.45초 동안 몸을 낮추며 바닥 화살표로 도약 방향을 알립니다.
- 스토커는 준비 시작 시 도약 방향을 고정하므로 옆으로 피할 수 있으며, 도약 이동은 벽에 막힙니다. 준비 중에는 접촉 피해가 발생하지 않고, 경직·사망 시 준비 동작과 표시를 취소합니다. 공격 피해와 재사용 대기시간은 기존 값을 유지합니다.
- 스토커는 심장 노출·경직 중 2.5배 피해를 받고, 평상시에는 피해를 30% 줄입니다. 시체에 접근하면 볼트 5발과 미보유 저주받은 유물 중 무작위 1개를 자동 획득합니다. 유물을 모두 보유한 경우 추가 유물은 지급하지 않습니다.
- 쇠뇌·근접·화약병·향로·잔류 화염 처치는 모두 몬스터의 경험치를 지급합니다. 처치 시점이 암전 중이면 경험치는 2배입니다. 경험치와 흡혈은 처치 순간 한 번만 지급됩니다.
- 레벨업마다 스탯 포인트 3개를 받습니다. 층 클리어 화면에서 공격력·체력·속도·화살통 강화에 배분합니다.
- 화살통 강화는 예비 볼트 10발과 재장전 시간 10% 감소입니다. 장전 시간 하한은 0.65초입니다.
- 클리어 화면에서는 미보유 유물 최대 3개 중 하나를 선택할 수 있습니다. 유물에는 이점과 불이익이 있으며, 피의 갈증은 어떤 공격 수단으로든 적을 처치하면 체력 12를 회복합니다.

## 소비 아이템·이계화

- **생명의 성수병**: 체력 45 회복, 슬로우 해제. 최대 3개 보유.
- **정화의 향로**: 기본 12초간 조명과 반경 5.5m의 지속 피해·밀치기. 현재 암전을 해제하고 연소 중 새 암전 발동을 막습니다. 재사용 시 10초 연장하며 남은 시간은 최대 20초입니다. 최대 2개 보유.
- **비산 화약병**: 곡사 투척 후 거리에 따라 최대 85의 폭발 피해, 4.5초간 잔류 화염. 최대 3개 보유.
- 새 게임에서는 각 소비 아이템을 1개씩 지급합니다. 던전의 유골함·보급함에 접근해 추가 획득합니다.
- 제단 활성화 시 24초, 남은 시간이 200초 이하가 되는 시점에 22초의 이계화가 발동합니다. 안개·촛불이 변하고 몬스터 이동이 빨라지며 스토커가 사냥 모드로 전환합니다.
- 심연의 수확자 유물은 암전 중 사격 공격력을 2.5배로 높이고 암전 시간을 8초 늘립니다.

## 프로젝트 구조

| 파일 | 역할 |
|---|---|
| `game.py` | 실행 진입점, 게임 상태, 스테이지, 몬스터 AI, 메인 태스크 루프 |
| `stage_config.py` | 층별 테마·대응 안내, 몬스터 편성 규칙 |
| `player_controller.py` | 입력, 카메라·이동, 체력·스태미나·성장·유물 |
| `combat_system.py` | 공통 피해·처치 보상, 쇠뇌, 볼트, 근접 전투, 탄약, 무기 애니메이션 |
| `inventory_system.py` | 소비 아이템, 보급함, 폭발·잔류 화염 |
| `monster.py` | 몬스터 모델, 애니메이션, 피해·특수 상태·시체 |
| `ui_manager.py` | HUD, 메뉴, 로딩, 성장 화면, 랭킹 JSON 입출력 |
| `compass_ui.py` | 360도 순환 나침반, 방위각 계산, 가장 가까운 제단·열린 관문 추적 |
| `world_gen.py` / `chunk.py` | 지형 규칙·길찾기 / 청크 모델·충돌체 생성 |
| `collision.py` / `geometry.py` | 이동 충돌 / 공통 3D 형상 |
| `audio_system.py` / `constants.py` | 음향 / 공통 설정·유물 정의 |

맵은 6m 셀, 36m 청크, 총 7×7청크의 252m×252m 공간입니다. 주변 청크 비동기 생성, 거리 기반 표시 제어, 지오메트리 병합과 촛불 광원 풀을 사용합니다. 엔진은 60 FPS 제한으로 설정되어 있으며 실제 성능은 환경에 따라 달라집니다.

`game.py`는 Panda3D `taskMgr`에 `update()`를 등록합니다. 플레이 중에는 플레이어 → 몬스터 → 적 투사체 → 음향·청크 표시 → 전투 → 소비 아이템 → 암전·제한시간 → 제단·관문 → HUD 순서로 갱신합니다.

효과음은 `assets/audio/`를 먼저 검색한 뒤 프로젝트 루트에서 찾습니다. `item_editor.py`는 독립 Tkinter 템플릿 편집기이며, `Weapon_Templates.json`은 현재 게임에서 사용하지 않습니다. `generate_audio.py`는 WAV 생성 도구이고 별도로 NumPy가 필요합니다.

## 회귀 검증

```bash
python -B -m unittest discover -s tests -v
```

창을 열지 않고 전투 피해, 보상, 암전 정화, 새 게임 초기화와 스테이지 간 상태 유지를 검증합니다.
공격 거절 시 스태미나 보존, 공격 수단별 보상 중복 방지, 얇은 벽·바닥·천장과 몬스터의 충돌 순서도 검증합니다.

`tests/test_stage_lifecycle.py`는 실제 에셋·UI·태스크를 사용해 시작 → 제단 3개 → 관문 → 성장 선택 → 다음 층 → 게임 오버 → 새 게임을 검증합니다. 로딩 취소, 광원·음향 연결 정리, 늦게 완료된 청크 해제도 검사합니다. 랭킹은 임시 파일에만 저장합니다. 실제 창의 렌더링과 소리 출력은 별도 플레이 확인이 필요합니다.

`tests/test_attack_telegraphs.py`는 특수 공격의 준비 시간, 단일 발동, 경직·사망 시 취소, 준비 중 접촉 피해 차단, 도약 회피·벽 충돌과 예고음의 위치·정리를 검증합니다.

`tests/test_stage_config.py`는 초반 편성 보존, 테마 순환과 100층까지의 몬스터 총수를 검증합니다. 스테이지 통합 테스트에서는 2~6층의 실제 편성과 로딩·진입 안내의 일치, 다음 층 진입 시 이전 몬스터 정리, 새 게임의 1층 복귀를 확인합니다.

`tests/test_navigation.py`는 동서남북 좌표, 359°↔0° 경계와 목표 선택을 검증합니다. 스테이지 통합 테스트에서는 실제 카메라 회전, 후방 표식, 제단→관문 전환, 화면 상태별 숨김과 다음 층 복구를 검사합니다.
