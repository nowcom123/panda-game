# Panda Game - Liminal Backrooms Infinite Loop

Panda3D 기반의 무한 절차적 백룸 공포 미로 탈출 게임입니다.

## 주요 특징
- **광활한 3D 심연 공간**: 6.0m 너비의 광폭 복도와 **13.0m 초대형 심연 천장** 및 3.0m 웅장한 출입문
- **제한된 거대 시설 맵 (252m x 252m)**: 7x7 청크(총 1,764개 구역)로 구성된 충분히 넓고 밀폐된 탈출 불가 미궁 외곽 벽체
- **칠흑의 어둠과 손전등 직선 빔**:
  - 촛불 갯수를 50% 감축하여 미지의 심연 어둠 극대화
  - 직선 원추형으로 강력하게 뻗어나가는 집중형 손전등(Spotlight) 빔 장착
  - 은은하게 타오르는 3D 고딕 촛불과 실시간 빛 깜빡임 연출
- **듀얼 공포 추격 괴물 AI**:
  - **항상 무작위 랜덤 스폰**: 게임 시작 및 재시작(`R`) 시마다 두 괴물이 26m~46m 거리의 복도에 무작위 스폰
  - **초대형 거대 흑사 (`LongBlackSerpent`)**:
    - 머리 폭 1.4m, 길이 1.8m, 총 연장 **약 13.5m의 거대한 칠흑의 대사**
    - 14개의 거대 마디가 실제 뱀처럼 실시간 S자 파동(Sinusoidal Undulation)을 그리며 슬리더링
    - 거대한 독니, 붉은 갈라진 혀(Forked Tongue) 날름거림, 번뜩이는 뱀 안광
    - 바닥을 기어오다가 복도 벽면을 타고 수직으로 올라가는 Wall-Climbing 물리 지원
  - **키 크고 팔이 긴 해골 괴물 (`TallSkeletonMonster`)**:
    - 13m 천장을 향해 치솟은 **약 4.2m 신장**의 초장신 해골 실루엣
    - 발목까지 축 늘어진 **비정상적으로 긴 2.7m 해골 팔**
    - 아래턱이 탈구되어 비정상적으로 길게 쩍 벌어진 **Unhinged Jaw** 두개골
    - 안와 속의 칠흑 같은 공허의 **검은 눈동자 (Void Black Eyes)**
    - 성큼성큼 걷는 음산한 보행 모션과 차가운 청백색 냉기 오라
- **순수 공포 몰입 HUD**: UI에서 괴물까지의 거리 표시를 완전히 배제하여 언제 어디서 습격당할지 모르는 긴장감 제공
- **8방향 이동 및 스테미나 시스템**: W, A, S, D 8방향 이동 (대각선 달리기 지원) 및 Shift 전력질주 시 스테미나 소모/회복 HUD
- **고성능 최적화**: 멀티스레드 비동기 청크 스트리밍, 촛대 원형 템플릿 인스턴싱, 드로우콜 병합(flattenStrong), 60 FPS 고정

## 조작법
- **이동**: `W`, `A`, `S`, `D` (8방향 대각선 이동 가능)
- **달리기**: `Shift` + 방향키 (스테미나 게이지 소모)
- **시선 전환**: `마우스`
- **마우스 커서 잠금/해제**: `ESC`
- **재시작**: `R`

## 실행 방법
```bash
# 의존성 패키지 설치
pip install panda3d simplepbr

# 게임 실행
python game.py
```
