# Panda Game - Liminal Backrooms FPS Escape

Panda3D 기반의 1인칭 호러 서바이벌 FPS 백룸 탈출 게임입니다.  
칠흑 같은 어둠 속에서 왼손 손전등과 오른손에 쥔 12발 권총만으로 1분 안에 비상탈출구를 찾아 5초간 문을 사수한 뒤 탈출해야 합니다.

## 주요 특징
- **시네마틱 인트로 화면 & 메인 메뉴**:
  - 게임 실행 시 거대한 미궁의 전경을 공중에서 360도 파노라마로 부드럽게 조망하는 시네마틱 카메라 연출
  - **START**: 1인칭 모드 진입 및 60초 서바이벌 탈출 시작
  - **RANK**: 역대 탈출 성공 기록(최단 시간 명예의 전당 TOP 5) 및 최근 플레이 도전 기록 모달 열람
  - **EXIT**: 게임 안전 종료
- **비상탈출문 5초 개방 홀드아웃 (난이도 상승)**:
  - 판타지풍 초록빛/기둥/비콘을 100% 제거하고 어둠 속에 숨겨진 중장갑 강철 방화문(Reinforced Blast Door)으로 재구성
  - 탈출문 2.8m 앞에서 **5초 동안 버텨야** 문이 열리고 탈출 성공
  - 홀드아웃 대기 중 쫓아오는 뱀 괴물과 해골 괴물을 12발 권총으로 스턴시키며 문 앞을 사수
  - 구역을 벗어나면 즉시 개방이 중단되고 타이머가 리셋되는 긴박한 디펜스 메커니즘
- **1인칭 듀얼 웰드 FPS & 발광 총알 궤적 (Bullet Tracer)**:
  - **왼손 손전등**: 어둠을 가르는 강력한 집중형 스포트라이트와 1인칭 플래시라이트 모델
  - **오른손 12발 권총**: 프레임, 슬라이드, 트리튬 야광 조준기가 구현된 1인칭 피스톨 모델
  - **선명한 총알 궤적**: 권총 격발 시 총구에서 탄착점까지 눈부시게 뻗어나가는 실시간 발광 탄도 라인 연출
  - 무기 바빙(Weapon Bobbing), 슬라이드 킥백 반동, 총구 화염(Muzzle Flash) 및 다이내믹 발사광
- **사격 적중 시 괴물 0.5초 경직 (Stun Mechanic)**:
  - 마우스 좌클릭(`Mouse1`)으로 정밀 히트스캔 사격
  - 적중 시 **0.5초간 즉시 이동 정지 및 고통스러운 피격 흔들림**
  - 스턴 상태 동안 플레이어 공격/사망 판정이 발생하지 않아 긴급 회피 및 문 사수 가능
- **자동 랭킹 기록 시스템 (`rankings.json`)**:
  - 탈출 성공 또는 사망(괴물 피격/시간 초과) 시 일시, 결과, 생존/탈출 시간, 잔여 탄약이 자동으로 로컬 JSON 파일에 영구 기록
  - 재시작(R) 키를 삭제하고 메인 메뉴 및 랭킹 모달로 연결되는 체계적인 게임 플로우 제공
- **듀얼 공포 추격 괴물 AI**:
  - 매 게임마다 플레이어와 이격된 복도에 무작위 스폰
  - **초대형 거대 흑사 (`LongBlackSerpent`)**: 길이 약 13.5m의 거대한 뱀, 실시간 S자 파동 및 벽면 슬리더링
  - **키 크고 팔이 긴 해골 괴물 (`TallSkeletonMonster`)**: 신장 4.2m, 2.7m의 긴 팔, 쩍 벌어진 턱과 검은 눈동자
- **광활한 252m x 252m 밀폐 시설 & 고성능 최적화**:
  - 13.0m 심연 천장, 7x7 청크(1,764개 타일)
  - 멀티스레드 비동기 청크 로딩, 드로우콜 병합(flattenStrong), 60 FPS 방어

## 조작법
- **이동**: `W`, `A`, `S`, `D` (8방향 대각선 이동 가능)
- **사격**: `마우스 좌클릭` (권총 발사, 12발 한정, 총알 궤적 표시)
- **달리기**: `Shift` + 방향키 (스테미나 소모)
- **시선 전환**: `마우스`
- **마우스 커서 잠금/해제**: `ESC`
- **메인 메뉴 복귀 / 랭킹 확인**: 게임 종료 후 화면 버튼 클릭

## 실행 방법
```bash
# 의존성 패키지 설치
pip install panda3d simplepbr

# 게임 실행
python game.py
```
